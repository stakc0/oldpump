# oldpump

A local, interaction-complete recreation of the April 24, 2024 pump.fun board reference. It is intentionally a static frontend with public sample data only: no wallet provider, transactions, authentication, or live market claims are connected.

## Run

```bash
npm install
npm run dev
```

Build and smoke test:

```bash
npm run build
npm test
```

The archived source material remains under `reference/` for provenance and is not loaded by the app UI.
